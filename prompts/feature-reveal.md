# One Feature in 12 Seconds

This starter illustrates a fictional meeting-notes feature. The editable example uses HyperFrames.

## Prompt

> Create a 12-second, 1280×720 product feature teaser with HyperFrames. Use the screenshots or recording I provide and show one task from before to after. Start with the original screen and one short sentence about the problem. Cut to the action and let the result settle on screen. Finish with the product name and one call to action. Keep the edit reproducible from a paused timeline and deliver editable HTML and a 30 fps MP4.
>
> - Product: [name]
> - Feature: [one change the viewer can see]
> - Proof: [before/after screenshots or a recording]
> - Next action: [one action and destination URL]
